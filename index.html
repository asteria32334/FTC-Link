FTC Link User Guide

Your smart coding partner designed specifically for FIRST Tech Challenge (FTC) robotics programming in Android Studio.

Built for FTC Teams

FTC Link lives directly inside your Android Studio environment. It helps you design robot mechanisms, write autonomous paths, configure motors and sensors, and debug Java/Kotlin robot code without ever switching windows.

Key Features

📄 Reads Your Open File Automatically

When you ask a question, FTC Link automatically reads the Java or Kotlin code tab you currently have open. It understands your motor names, subsystem variables, and OpMode structure instantly.

🌐 Multi-Language Support

Ask in English, Turkish, or any preferred language. FTC Link detects your language automatically and responds in the exact same language with clear explanations.

💾 Automatic Memory & Persistent History

FTC Link remembers your past questions and robot configurations even if you close and reopen Android Studio. You can build multi-step robot code smoothly across multiple sessions.

💻 Copy-Ready Code Blocks

Get ready-to-use code snippets formatted perfectly for FTC libraries (FTC SDK, RoadRunner, Pedro Pathing, REV Hardware, Telemetry) with clear step-by-step guidance.

🧹 One-Click Clear Button

Want to start a new project or wipe old chat history? Simply click the Clear button at any time to refresh your chat panel.

How to Install

  1. Open Android Studio.
  2. Go to Settings (or Preferences on Mac) > Plugins.
  3. Select the Marketplace tab and search for "FTC Link".
  4. Click Install and restart Android Studio when prompted.

Getting Your Free API Key (Step-by-Step)

FTC Link uses Google's Gemini infrastructure to power its responses. You will need a free API key to get started:


1 Open your browser and go to aistudio.google.com.

2 Sign in with any Google Account (personal or team account).

3 Click "🔑" on the left panel, then select "Create API key in new project".

4 Copy the generated key to your clipboard.

5 Open Android Studio, enter the key when prompted, or go to File > Settings > FTC Link and paste your key into the text field.

How to Use FTC Link

Open the FTC Link panel on the right sidebar of Android Studio and start typing. Here are some examples of what you can ask:

// Example Questions:
"Write a Mecanum drive TeleOp mode for 4 REV motors."
"Add an encoder velocity control function to my open ArmSubsystem class."
"How do I set up my autonomous trajectory using RoadRunner?"
"Debug the encoder error in my current active OpMode."

Managing Settings & History

  • Changing API Keys: You can update or change your key anytime under File > Settings > FTC Link without reinstalling the plugin.
  • Clearing Chat History: To reset the panel and erase saved messages, click the Clear button at the bottom right corner and confirm the dialog box.
