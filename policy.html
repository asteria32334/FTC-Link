Privacy Policy for FTC Link

Last Updated: October 28, 2026

FTC Link is an integrated Android Studio plugin core built specifically for FIRST Tech Challenge (FTC) robot programming, code analysis, and subsystem optimization.

This Privacy Policy outlines how data is handled, stored, and processed when using the FTC Link plugin inside your IDE environment.

1. Data Collection and Usage

  • API Key Storage: FTC Link operates on a "Bring Your Own Key" (BYOK) structure. Your Google Gemini API key is stored locally on your machine using IntelliJ’s native storage properties (PropertiesComponent). Your API key is never collected, stored, or transmitted to any external servers owned by us.
  • Active Code Scope & Context: When you send a query, the text contents of your active open editor file (such as Java or Kotlin OpModes or Subsystems) are bundled with your prompt and sent directly to the Google Gemini API for real-time analysis. We do not store or track your proprietary robot code.
  • Local Session History: Your conversation history is cached locally within IDE properties to maintain chat context across sessions. This data remains strictly on your local computer.

2. Third-Party Services

FTC Link communicates directly with Google AI (Gemini API) to process code analysis queries. We do not integrate any external analytics, tracking scripts, telemetry pixels, or third-party advertising frameworks into the plugin.

3. Data Security

We prioritize developer privacy and code security. Because credentials and interaction logs reside exclusively within your local development workspace, external unauthorized access to your source code or keys via FTC Link is prevented.

4. Changes to This Privacy Policy

We may update our Privacy Policy periodically to reflect plugin enhancements or legal compliance changes. Any updates will be published directly to this page with a revised date.

5. Contact Us

If you have questions, concerns, or inquiries regarding this Privacy Policy or data handling in FTC Link, please submit an issue on our official project repository or contact our developer support channel.
